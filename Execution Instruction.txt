# Execution Instructions

---

 1. Install Ollama

Download and install Ollama from:

https://ollama.com/download

Verify installation:

ollama --version

---

2. Download Llama 3.2 (1B)

After installing Ollama, open a terminal and execute:

```bash
ollama pull llama3.2:1b
```

Verify the model:

```bash
ollama list
```

Expected Output:

```
NAME
llama3.2:1b
```


3.Create a Virtual Environment

Windows

```bash
python -m venv .venv
```

Activate:

```bash
.venv\Scripts\activate
```

---

4.Install Required Packages

```bash
pip install -r requirements.txt
```

---

5. Configure Environment Variables

Create a `.env` file in the project root directory.

Example:

```env
OLLAMA_MODEL=llama3.2:1b

TAVILY_API_KEY="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"

CHROMA_DB=knowledge_base
```

---

6 Start the Application

Run the Streamlit application:

```bash
streamlit run streamlit_app.py
```

The application will be available at:

```
http://localhost:8501
```

---

# Application Workflow

1. Enter a research topic.
2. The application checks for semantically similar research.
3. If similar research exists:
   - Retrieves relevant documents directly from ChromaDB.
4. Otherwise:
   - Planner Agent generates research questions.
   - Search Agent retrieves trusted web sources.
   - Scraper Agent extracts webpage content.
   - Documents are stored in ChromaDB.
   - Retriever Agent performs semantic retrieval.
   - Enterprise Intelligence Agent generates an executive report.

# Troubleshooting

### Ollama model not found

```bash
ollama pull llama3.2:1b
```

---

### ChromaDB not installed

```bash
pip install chromadb
```

---

### Streamlit not installed

```bash
pip install streamlit
```

---

### Invalid Tavily API Key

Ensure your `.env` file contains a valid API key.

Example:

```env
TAVILY_API_KEY=tvly-xxxxxxxxxxxxxxxxxxxxxxxx
```

---

### Port Already in Use

Run Streamlit on another port:

```bash
streamlit run streamlit_app.py --server.port 8502
```

# System Requirements

- Operating System: Windows 10/11, Linux, or macOS
- Python: 3.12+
- RAM: Minimum 8 GB (16 GB Recommended)
- Disk Space: Approximately 3 GB
- Internet Connection: Required for Tavily Search API
- Local LLM: Ollama with Llama 3.2 (1B) installed
